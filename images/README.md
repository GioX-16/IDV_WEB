# Imágenes necesarias para el sitio web IDV

## Archivos de imagen requeridos:

### 1. `LOGO_IDV.png`
- **Ubicación**: `images/LOGO_IDV.png`
- **Descripción**: Logo oficial de la Iglesia del Dios Viviente
- **Tamaño recomendado**: 40x40px o mayor (se ajustará automáticamente)
- **Formato**: PNG con fondo transparente preferiblemente

### 2. `Background_Hero_Banner.png`
- **Ubicación**: `images/Background_Hero_Banner.png`
- **Descripción**: Imagen de fondo para la sección hero
- **Tamaño recomendado**: 1920x1080px o mayor
- **Formato**: PNG
- **Nota**: Se aplicará con opacidad del 60% para no interferir con el texto

### 3. `erasebg-transformed.png`
- **Ubicación**: `images/erasebg-transformed.png`
- **Descripción**: Imagen de la familia de la iglesia (como la que ya tienes)
- **Tamaño recomendado**: 400x300px o mayor
- **Formato**: PNG preferiblemente
- **Nota**: Esta imagen reemplazará el placeholder actual

### 4. `Convencion LOGO.png`
- **Ubicación**: `images/Convencion LOGO.png`
- **Descripción**: Logo circular rojo de la convención de iglesias
- **Tamaño recomendado**: 80x80px o mayor
- **Formato**: PNG con fondo transparente preferiblemente
- **Nota**: Se mostrará en la parte izquierda del hero

## Instrucciones:
1. Coloca las imágenes en esta carpeta (`images/`)
2. Asegúrate de que los nombres de archivo coincidan exactamente
3. Las imágenes se ajustarán automáticamente al diseño responsive
